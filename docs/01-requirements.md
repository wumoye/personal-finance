# Personal Finance Manager

# V1 产品需求

## 1. 产品定位

Personal Finance Manager 是个人资金管理系统。

它不仅用于记录消费，还用于回答：

- 我的钱在哪里？
- 我现在拥有多少资产？
- 我目前有多少负债？
- 我的净资产是多少？
- 这个月收入多少？
- 这个月实际花了多少？
- 工资应该如何分配？
- 每张信用卡欠多少钱？
- 本月准备还多少钱？
- 还款后还剩多少负债？
- 本月底预计还能剩多少钱？

V1 首要目标：

完全替代当前 Excel 的核心资金管理功能。

---

# 2. 用户

V1 首先面向单个个人用户。

系统架构仍必须支持不同用户之间的数据隔离。

V1 暂不实现：

- 家庭共享
- 企业账户
- 团队账户
- 管理员后台

---

# 3. 目标平台

V1：

Responsive Web + PWA

必须支持：

- Desktop Browser
- Android Browser/PWA
- iPhone Browser/PWA
- Tablet

Desktop 与 Mobile 应采用适合各自设备的布局。

---

# 4. Dashboard

Dashboard 显示用户整体财务状态。

必须包含：

- 净资产
- 总资产
- 总负债
- 本月收入
- 本月支出
- 本月投资
- 预计月底余额
- 信用卡总负债
- 最近 12 个月净资产趋势
- 本月主要消费分类

提供快捷操作：

- 记一笔
- 转账
- 月度计划
- 信用卡还款

---

# 5. Account Management

用户可以自由创建账户。

Account Type：

- BANK
- CREDIT_CARD
- CASH
- WALLET
- INVESTMENT
- PENSION
- OTHER

账户字段至少包含：

- 名称
- 类型
- 币种
- 初始余额
- 是否计入净资产
- 排序
- 是否启用

支持：

- 新增
- 编辑
- 停用
- 排序

历史账户不建议直接删除。

---

# 6. Category Management

用户可以管理收入与支出分类。

Category Type：

- INCOME
- EXPENSE

支持：

- 新增
- 修改
- 停用
- 排序

系统可以提供初始化分类。

具体分类不得写死在业务代码。

---

# 7. Transaction

支持：

- 收入
- 支出

字段至少包含：

- 金额
- 日期
- Account
- Category
- 描述
- 备注

支持：

- 新增
- 编辑
- 删除
- 查看列表

支持筛选：

- 月份
- Account
- Category
- Income / Expense
- 关键词

---

# 8. Quick Entry

Mobile 必须提供快速记账体验。

目标：

常规记录尽可能在 5～10 秒完成。

提供：

支出 / 收入 / 转账

切换。

优先显示：

- 金额
- Account
- Category
- 日期
- 备注

可以显示常用分类快捷入口。

---

# 9. Transfer

用户可以在任意两个允许转账的 Account 之间记录资金转移。

字段：

- 转出 Account
- 转入 Account
- 金额
- 日期
- 备注

Transfer 不属于收入和支出。

---

# 10. Monthly Plan

月度资金计划是 V1 核心功能。

用户可以按月份创建资金计划。

例如：

2026-08

计划收入：
工资 ¥450,000

资金计划：
房租 ¥108,600
信用卡还款 ¥130,000
投资 ¥100,000
生活预算 ¥60,000

系统计算：

- 计划收入
- 计划支出
- 计划信用卡还款
- 计划投资
- 预计剩余资金

支持：

- 新建月份
- 编辑计划
- 添加计划项目
- 删除计划项目
- 调整排序
- 复制上个月计划

后续可以显示：

计划 vs 实际。

---

# 11. Credit Card

信用卡是特殊类型 Account。

信用卡可以配置：

- 信用额度
- 结账日
- 还款日
- 默认还款 Account
- 币种

信用卡页面显示：

- 当前欠款
- 本月新增消费
- 利息 / 手续费
- 本月计划还款
- 本月实际还款
- 预计还款后欠款
- 信用额度使用率

支持多张信用卡。

不得假定用户固定使用某些信用卡。

---

# 12. Recurring Rules

用户可以创建周期性项目。

例如：

- 房租
- 手机
- 网络
- 软件订阅
- 保险
- iDeCo
- 固定投资

至少支持 MONTHLY。

字段包括：

- 名称
- 金额
- Category
- Account
- 周期
- 开始日期
- 结束日期（可选）
- 是否启用

生成新的 Monthly Plan 时，可以自动加入符合条件的固定项目。

生成后允许用户修改。

---

# 13. Asset Management

系统需要管理：

- 银行现金
- 现金
- 钱包
- 投资账户
- iDeCo / Pension

Dashboard 可以按类型聚合资产。

支持 Asset Snapshot，用于保存历史资产状态。

用于生成：

- 总资产
- 资产构成
- 净资产趋势

---

# 14. Settings

至少包含：

- Account 管理
- Category 管理
- Recurring Rule 管理
- 基础用户设置

后续可以加入：

- 数据导入
- 数据导出
- 主题
- 币种

以下功能不属于第一批开发：

- OCR

- 信用卡 API 自动同步

- Expo Native App
- 多币种复杂换算

但架构不应明显阻碍未来增加这些功能。

---

# 16. V1 成功标准

V1 的最终业务验收标准：

用户能够连续一个月不再依赖原 Excel 完成核心资金管理。

必须能够完成：

收入记录
→ 支出记录
→ 账户转账
→ 月度资金计划
→ 信用卡管理
→ 固定支出
→ 资产管理
→ Dashboard 查看整体财务状态
